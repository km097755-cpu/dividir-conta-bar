# Dividir a conta do bar

Calculadora que divide a conta: comida entre todos, bebida alcoólica só entre quem bebeu, sem perder centavos. Não cobra taxa de serviço. Tem campo para a chave Pix de quem pagou e botão que copia a mensagem de cobrança de cada pessoa. Autoteste: abra com `?teste` no fim do endereço.

Página única (HTML, CSS e JavaScript no mesmo arquivo). Não precisa instalar nada: baixe o `index.html` e abra com duplo clique no navegador.

Feito em português do Brasil, valores em reais.
